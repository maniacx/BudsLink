# Realme / Oppo/ OnePlusEarbuds

* Bluetooth socket for Realme / Oppo/ OnePlus buds can be accessed by only one application at a time. Close other Realme / Oppo/ OnePlus companion or monitoring apps, before using BudsLink.
* Feature availability varies by model.
* Credits to shitan198u for contributing the Realme / Oppo/ OnePlus Buds protocol.

Most settings are self-explanatory and similar to those available on OEM app. Settings specific to BudsLink are explained below.

## Icon selection

* Device icons: Select from the available options for your headset type (single-battery or dual-battery devices).
* Case icon: For models that report a case battery, an additional case icon can be selected.

## Compatibility
<br>

**Help update the compatibility list**

If your device is missing from the list or you have additional compatibility information, please help improve the documentation by submitting a pull request to the [Documentation](https://github.com/maniacx/BudsLink/blob/Documentation/docs/Devices/Realme.md) branch to update this page, or opening an issue with your device model and details of features you tested.

<br>

**New Device Configuration**

If your device configuration is missing, you can request its addition by opening an issue with screenshots of the OEM app, the output of `bluetoothctl info <device-MAC>`, and product IDs from runtime.log. To obtain the IDs, connect your earbuds, launch BudsLink, and check the log. Alternatively, submit a pull request to the main branch with the new device configuration after successfully testing it.
